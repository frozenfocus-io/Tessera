# Eigene Testdateien

Hier kannst du Schematics zum Ausprobieren ablegen (`.schem`, `.litematic`, `.nbt`). Alles in diesem Ordner außer dieser Datei bleibt lokal und wird nicht eingecheckt.

Der Test gegen die Beispieldatei aus Etappe 1 läuft, wenn sie hier liegt und du ihren Pfad angibst:

```sh
TESSERA_SAMPLE_SCHEM=samples/a05cccd2-32011.schem npm test
```
